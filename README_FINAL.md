## ⚡ Comece em 5 Minutos

### 1. Inicie o MySQL (Docker)
```bash
docker run -d --name mysql_dsw -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=db_DSW_MIGUEL_MAXIMUS_3TIB -p 3306:3306 mysql:latest
```

### 2. Inicie o Backend
```bash
cd backend
npx prisma migrate dev --name init
npm start
```

### 3. Inicie o Frontend
```bash
cd frontend
npm run dev
```

### 4. Abra no Navegador
```
http://localhost:5173
```

## 🆘 Se Algo Não Funcionar

### "Não consigo conectar à API"
- Verifique se backend está rodando: `npm start`
- Confirme MySQL: `docker ps`
- Veja console do navegador: `F12`

### "Frontend mostra erro"
- Verifique backend está em http://localhost:3000
- Recarregue página: `Ctrl+R`
- Limpe cache: `Ctrl+Shift+Del`

### "Database não conecta"
- Inicie Docker: `docker run ... mysql:latest`
- Verifique .env do backend
