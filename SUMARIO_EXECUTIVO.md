## 🚀 Para Iniciar

### 3 Passos, 5 Minutos

**Terminal 1:**
```bash
docker run -d --name mysql_dsw -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=db_DSW_MIGUEL_MAXIMUS_3TIB -p 3306:3306 mysql:latest
```

**Terminal 2:**
```bash
cd backend
npx prisma migrate dev --name init
npm start
```

**Terminal 3:**
```bash
cd frontend
npm run dev
```

**Então:** Abra http://localhost:5173
