## 🚀 Para Começar (3 Passos)

1. **Docker Setup**
   ```
   docker run -d --name mysql_dsw -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=db_DSW_MIGUEL_MAXIMUS_3TIB -p 3306:3306 mysql:latest
   ```

2. **Criar Banco**
   ```
   cd backend && npx prisma migrate dev --name init
   ```

3. **Rodar Servidor**
   ```
   npm start
   ```

**Tempo: 10 minutos** ⏱️
